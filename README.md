# 🚗 Traffic Accident Data Analysis

## 📌 Objective
Analyze traffic accident data to identify patterns related to:
- Road conditions
- Weather
- Time of day

## 📊 Dataset
- Source: Kaggle (US Accidents Dataset)
- Sample Size: 100,000 records

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📈 Key Analysis
- Accident severity distribution
- Accidents by day & hour
- Weather impact analysis
- Correlation heatmap
- Geographic accident hotspots

## 📌 Key Insights
- Most accidents occur on weekdays
- Peak hours: Morning & evening traffic
- Weather conditions significantly impact accident frequency
- Certain cities show higher accident concentration

## 📂 Project Files
- `US_Accidents_Data_Analysis.ipynb` → Main analysis notebook

## 🚀 Conclusion
This project demonstrates how data visualization and analysis can help understand accident patterns and improve road safety strategies.
